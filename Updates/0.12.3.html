AwakeMac 0.12.3

Clicking the menu-bar icon now opens only the session panel, without bringing the Settings window forward.

First launch and reopening AwakeMac from Applications now use the same menu-bar popover instead of opening a separate session window.

Session controls, keyboard editing, and opening Settings from the options menu continue to work normally.

Requires macOS 14 or later and a valid AwakeMac license key. Supports Apple silicon and Intel.
