WakeBee 0.14.0

A new name and a simpler purchase flow.

  • The app, Settings, and installer now use the WakeBee name and the existing sun icon. The menu bar stays icon-only, with an optional countdown.
  • Purchases and license activation use Polar. Existing Polar licenses and saved activations continue working with the WakeBee name.
  • License activation checks the WakeBee product, remembers this Mac’s activation for retries, and releases the device slot when you remove the license.
  • Closed-lid setup errors now show their details directly, with a Copy setup details button for troubleshooting.
